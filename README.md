# Pocket Option Background

Отдельное Windows-приложение на Electron для управления окном Pocket Option и его постоянной браузерной сессией.

## Текущий этап

Это начальная реализация оболочки приложения. Она не изменяет существующие каталоги расширения и торгового ядра.

### Реализовано в исходниках

- Главное окно управления открывается первым; Pocket Option автоматически не запускается.
- Постоянный Electron session partition: `persist:pocket-option-background`.
- Закрытие главного и сайта скрывает соответствующее окно; выход доступен через системный трей.
- Отдельный мини-виджет, не закреплённый поверх остальных окон.
- Локальные настройки и журнал JSONL.
- Диагностическая проверка по расписанию 5 минут.
- Проверка доступности сайта каждые 30 секунд, ограниченное восстановление и перезагрузка.
- Экспорт журналов в ZIP.
- Автоматическая проверка и загрузка обновлений через GitHub Releases; установка после подтверждения или при штатном выходе.
- Экспериментальный сбор входящих WebSocket-кадров Pocket Option через Chromium DevTools Protocol.
- Чтение каталога `updateAssets`, явная классификация OTC и отклонение неоднозначных символов.
- Инкрементальное построение свечей по десяти таймфреймам для подтверждённых OTC-активов.
- Локальное SQLite-хранилище: закрытые live- и полученные OHLC-исторические свечи сохраняются пакетами; последние 300 свечей на актив/таймфрейм восстанавливаются после перезапуска.

## Важные ограничения первого этапа

1. Пользователь входит в Pocket Option вручную. Приложение не запрашивает и не хранит пароль.
2. Баланс читается отдельным DOM-адаптером по селекторам, которые используются в текущем коде `3.6.0_0/inject.js`. Селекторы сайта могут измениться; если структура сайта изменилась, статус останется «нет свежих данных», а не покажет выдуманный баланс.
3. Переключение DEMO/REAL выполняется навигацией на известные маршруты кабинета и считается успешным только после подтверждения режима и баланса адаптером. Маршрут REAL и подтверждение нужно проверить на реальном аккаунте перед использованием.
4. Этот каталог не включает автоматическую торговлю и не выставляет сделки. Периодическая диагностика проверяет приложение, сетевое соединение, renderer и адаптер сайта. Отдельное торговое ядро не считается работающим, если оно не подключено как отдельный модуль.
5. В этой версии нет гарантии, что сайт или сервер сохранят соединение при скрытом окне, изменении сети, режиме сна или ограничениях Windows.
6. WebSocket capture и сбор свечей пока экспериментальны: тесты выполнены на mock-потоке, живой запуск на Windows/Pocket Option ещё не подтверждён.
7. Загрузка глубокой исторической истории с сервера, ручная разметка, поиск похожих ситуаций, торговый журнал и автоторговля ещё не реализованы.
8. SQLite использует встроенный `node:sqlite` Electron runtime; отдельная проверка запускается в Windows CI.

## Запуск для разработки

Требуется Node.js LTS и Windows 11.

```powershell
cd Pocket-Option-Background
npm install
npm run check
npm start
```

Сборка установщика:

```powershell
npm run dist
```

Публикация обновления: увеличить `version` в `package.json`, отправить тег `vX.Y.Z`. Workflow `.github/workflows/release.yml` соберёт Windows NSIS установщик и опубликует GitHub Release с метаданными electron-builder (`latest.yml`). Установленная программа проверяет обновления после запуска и каждые 6 часов, автоматически скачивает найденную версию.

## Хранение данных

Профиль сайта, авторизация и cookies хранятся в Electron persistent session. Настройки и журналы — в каталоге userData приложения. Удаление этих данных удалит сохранённую авторизацию.
