# Pocket Option Background

Отдельное Windows-приложение на Electron для управления окном Pocket Option и его постоянной браузерной сессией.

## Скачать и установить (Windows x64)

**[Скачать установщик Pocket-Option-Background-Setup-0.1.1.exe](https://github.com/Maestro-777/pocket-option-app/actions/runs/44722773954/artifacts/14622093266)**

Ссылка ведёт на ZIP-артефакт успешной сборки GitHub Actions. После скачивания:

1. Распакуйте архив.
2. Запустите `Pocket-Option-Background-Setup-0.1.1.exe`.
3. Следуйте инструкциям установщика.

[Открыть последнюю историю CI-сборок](https://github.com/Maestro-777/pocket-option-app/actions/workflows/ci.yml) — в последней успешной сборке откройте раздел **Artifacts** и скачайте `Pocket-Option-Background-win-x64`.

> Артефакты GitHub Actions временные и удаляются по истечении срока хранения (для текущей сборки — 4 декабря 2026 года). Установщик не подписан цифровым сертификатом, поэтому Windows SmartScreen может показать предупреждение.

## Запуск в режиме разработчика

### Требования

- Windows 10/11 x64.
- [Node.js 22 LTS](https://nodejs.org/) (вместе с npm).
- [Git for Windows](https://git-scm.com/download/win).

### Получение исходников и установка зависимостей

Откройте PowerShell и выполните:

```powershell
git clone https://github.com/Maestro-777/pocket-option-app.git
cd pocket-option-app
npm install
```

### Проверка и запуск

```powershell
# Проверить синтаксис JavaScript
npm run check

# Запустить модульные тесты
npm test

# Запустить приложение в режиме разработки
npm start
```

После `npm start` откроется Electron-приложение. Для разработки можно изменять исходники и перезапускать приложение командой `npm start`.

### Локальная сборка установщика

```powershell
npm run dist
```

Готовый Windows NSIS установщик появится в каталоге `dist`. Команда сборки использует `--publish never`: она создаёт установщик локально и не пытается публиковать его в GitHub Releases.

## Текущий этап

Это начальная реализация оболочки приложения. Она не изменяет существующие каталоги расширения и торгового ядра.

### Реализовано в исходниках

- Главное окно управления открывается первым; Pocket Option автоматически не запускается.
- Постоянный Electron session partition: `persist:pocket-option-background`.
- Закрытие главного и сайта скрывает соответствующее окно; выход доступен через системный трей.
- Отдельный мини-виджет, не закреплённый поверх остальных окон.
- Локальные настройки и журнал JSONL.
- Диагностическая проверка по расписанию 5 минут.
- Проверка доступности сайта каждые 30 секунд, ограниченное восстановление и перезагрузка.
- Экспорт журналов в ZIP.
- Автоматическая проверка и загрузка обновлений через GitHub Releases; установка после подтверждения или при штатном выходе.
- Экспериментальный data-only Market Data adapter: наблюдение за разрешёнными WebSocket-событиями, нормализация тиков/OTC и OHLC-истории, in-memory буферы по активам.
- Диагностический экран рыночного потока показывает число активов/тиков и свежесть последних наблюдений.

## Важные ограничения первого этапа

1. Пользователь входит в Pocket Option вручную. Приложение не запрашивает и не хранит пароль.
2. Баланс читается отдельным DOM-адаптером по селекторам, которые используются в текущем коде `3.6.0_0/inject.js`. Селекторы сайта могут измениться; если структура сайта изменилась, статус останется «нет свежих данных», а не покажет выдуманный баланс.
3. Переключение DEMO/REAL выполняется навигацией на известные маршруты кабинета и считается успешным только после подтверждения режима и баланса адаптером. Маршрут REAL и подтверждение нужно проверить на реальном аккаунте перед использованием.
4. Market Data adapter — прототип: данные пока хранятся только в памяти. Реальное получение всех OTC-пар одновременно, история неактивных инструментов и задержки ещё не проверены в живой сессии Pocket Option. WebSocket-события из MAIN world считаются недоверенными данными.
5. Этот каталог не включает автоматическую торговлю и не выставляет сделки. Периодическая диагностика проверяет приложение, сетевое соединение, renderer и адаптер сайта. Отдельное торговое ядро не считается работающим, если оно не подключено как отдельный модуль.
6. В этой версии нет гарантии, что сайт или сервер сохранят соединение при скрытом окне, изменении сети, режиме сна или ограничениях Windows.

## Хранение данных

Профиль сайта, авторизация и cookies хранятся в Electron persistent session. Настройки и журналы — в каталоге userData приложения. Удаление этих данных удалит сохранённую авторизацию.
