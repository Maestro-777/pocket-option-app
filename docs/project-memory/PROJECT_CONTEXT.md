# Контекст проекта

## Цель
Создать Windows Electron-приложение для Pocket Option с ручной разметкой исторических OTC-ситуаций, поиском похожих ситуаций по общей базе примеров, объяснением сигналов, статистикой фактической доходности и автоматической торговлей с ограничениями риска.

Пользователь хочет использовать собственные размеченные примеры, а не полагаться только на стандартные индикаторы. Решения алгоритма должны быть прозрачными и проверяемыми.

## Репозитории
### Основной: pocket-option-app
https://github.com/Maestro-777/pocket-option-app

Целевой репозиторий Electron-приложения и его будущего торгового ядра. Текущий package.json указывает версию 0.1.1. README описывает оболочку управления окном Pocket Option и постоянной сессией.

### Вторичный: pocket-tracker
https://github.com/Maestro-777/pocket-tracker

Справочник существующего кода и протоколов, прежде всего каталога 3.6.0_0. Не считать архитектуру Chrome extension автоматически подходящей для Electron и не менять этот репозиторий вместо основного без отдельной задачи.

Архитектура расширения:
https://github.com/Maestro-777/pocket-tracker/blob/main/3.6.0_0/ARCHITECTURE.md
