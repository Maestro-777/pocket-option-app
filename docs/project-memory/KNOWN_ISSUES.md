# Известные проблемы и риски

## Подтверждено источниками
1. Основное Electron-приложение 0.1.1 — оболочка управления, торговое ядро и автоторговля не подключены.
2. npm run check — синтаксическая проверка, не интеграционный тест.
3. Запуск и сборка на Windows в этой сессии не подтверждены.
4. DOM-селекторы баланса/торговых элементов могут измениться.
5. WebSocket-каталог активов не доказывает одновременное исполнение.
6. executeTrade() в описании расширения управляет текущим торговым DOM.
7. modules/* исполняются в main process и имеют его полномочия; sandbox отсутствует.
8. window.postMessage требует строгой проверки source/origin/schema.
9. В архитектуре расширения упомянут HMAC-секрет в JS; клиентский встроенный секрет нельзя считать секретным.
10. Телеметрия расширения может содержать финансовые данные; при переносе нужно пересмотреть согласие, минимизацию и хранение.

## Не проверено
- Устойчивость соединения при скрытом окне, сне Windows и сетевых обрывах.
- Актуальность URL DEMO/REAL для всех регионов и аккаунтов.
- Точность DOM-адаптера на текущем сайте.
- Полнота свечей по всем OTC-парам.
- Исполнение по неактивной паре.
- Прибыльность алгоритма поиска похожих ситуаций.
- Работа установщика и обновлений на чистой Windows.

## Документационные расхождения
README/package.json указывают 0.1.1, Developer Guide/User Guide указывают 0.1.0. При изменениях синхронизировать документацию.

## Предосторожности
- Не хранить секреты и приватные финансовые данные в Git.
- Не отправлять REAL-сделки без отдельного разрешения и защит.
- Не выполнять быстрое переключение пары + клик без проверки фактического инструмента.
- Не включать post-entry признаки в поиск.
- Не смешивать DEMO и REAL без явной маркировки.

## Риски новой реализации в рабочей ветке
- CDP WebSocket bridge и MAIN-world injection пока не проверены на живом Pocket Option; CSP, изменения приложения или иная схема соединения могут повлиять на работу.
- Наличие updateStream в исходнике расширения не подтверждает, что в реальном сеансе Electron приходят все OTC активы.
- Исторические payload могут различаться по форме; OHLC parser намеренно отбрасывает неоднозначные варианты, поэтому часть истории может не появиться.
- История от платформы может приходить только для выбранного на сайте актива; загрузка всех историй параллельно не доказана.
- Market-data snapshot ограничен по количеству тиков/свечей и не является бесконечным архивом.
- similarity formula и patternLength=30 не калиброваны на реальных размеченных данных.
- TradingGate не является execution adapter; сделок он не открывает.
- Состояние открытых сделок и seenSignals пока не переживает перезапуск как полноценный торговый ledger.
- UI ручной разметки требует проверки на реальных данных, разных разрешениях и больших диапазонах.

- SignalScheduler сохраняет lastScanned bar keys только в памяти; после перезапуска возможен повторный сигнал на ещё свежем баре. Перед автоторговлей нужна персистентная идемпотентность.
- Лимит кандидатов maxOpenTrades пока не учитывает реальные открытые позиции, поскольку trade ledger/execution adapter ещё отсутствуют.
- Scheduler анализирует только те OTC активы, которые фактически присутствуют в каталоге MarketDataService; полнота каталога не подтверждена.
- Scheduler default включает все 10 таймфреймов; нагрузку на большом каталоге нужно измерить.

- DOM-селекторы суммы, экспирации, активного инструмента и кнопок перенесены/адаптированы из `pocket-tracker`, но не проверены на текущей живой версии Pocket Option.
- `window.__PT_TRADE_COMMAND__` fail-closed: если активный инструмент нельзя подтвердить, сумма/экспирация не применяются или кнопка не найдена, сделка не отправляется.
- После UI-клика нет подтверждённого брокерского open acknowledgement; статус остаётся SUBMITTED_UNCONFIRMED до close-event.
- Close-event может не содержать пары/направления. В таком случае однозначное сопоставление возможно только при одном подходящем незавершённом ордере; иначе событие сохраняется как unmatched.
- Мультисделочный режим >1 остаётся заблокирован до фактического подтверждения, что close-event содержит достаточную информацию о паре. Даже после этого две незавершённые сделки по одной паре не допускаются.
- Реальная проверка на DEMO-аккаунте не проводилась в этой сессии; автоторговля по умолчанию выключена.
