# Известные проблемы и риски

## Подтверждено источниками
1. Основное Electron-приложение 0.1.1 — оболочка управления, торговое ядро и автоторговля не подключены.
2. npm run check — синтаксическая проверка, не интеграционный тест.
3. Запуск и сборка на Windows в этой сессии не подтверждены.
4. DOM-селекторы баланса/торговых элементов могут измениться.
5. WebSocket-каталог активов не доказывает одновременное исполнение.
6. executeTrade() в описании расширения управляет текущим торговым DOM.
7. modules/* исполняются в main process и имеют его полномочия; sandbox отсутствует.
8. window.postMessage требует строгой проверки source/origin/schema.
9. В архитектуре расширения упомянут HMAC-секрет в JS; клиентский встроенный секрет нельзя считать секретным.
10. Телеметрия расширения может содержать финансовые данные; при переносе нужно пересмотреть согласие, минимизацию и хранение.
11. Текущий MarketDataHub хранит данные только в RAM; перезапуск очищает свечи.
12. CDP capture проверен unit-тестами с mock debugger, но не на живом Electron/Pocket Option.
13. OTC-фильтр теперь использует updateAssets и явный суффикс `_OTC`; live-каталог и фактические названия ещё не проверены на текущем Pocket Option. Символы без маркера и с неоднозначным alias намеренно отклоняются.
14. Исторические свечи ещё не загружаются; MarketDataHub пока строит свечи из поступающих тиков.
15. При уже подключённом Chromium debugger capture переходит в unavailable, не отключая чужой debugger.

## Не проверено
- Устойчивость соединения при скрытом окне, сне Windows и сетевых обрывах.
- Актуальность URL DEMO/REAL для всех регионов и аккаунтов.
- Точность DOM-адаптера на текущем сайте.
- Полнота свечей по всем OTC-парам.
- Фактическое поведение CDP Network.webSocketFrameReceived на текущем Pocket Option и Windows Electron 45.3.4.
- Достаточность лимитов 150 активов × 1000 свечей на серию для реального числа активов/частоты тиков.
- Исполнение по неактивной паре.
- Прибыльность алгоритма поиска похожих ситуаций.
- Работа установщика и обновлений на чистой Windows.

## Документационные расхождения
README/package.json указывают 0.1.1, Developer Guide/User Guide указывают 0.1.0. При изменениях синхронизировать документацию.

## Предосторожности
- Не хранить секреты и приватные финансовые данные в Git.
- Не отправлять REAL-сделки без отдельного разрешения и защит.
- Не выполнять быстрое переключение пары + клик без проверки фактического инструмента.
- Не включать post-entry признаки в поиск.
- Не смешивать DEMO и REAL без явной маркировки.
