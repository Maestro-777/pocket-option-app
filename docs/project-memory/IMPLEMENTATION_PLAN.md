## Этап 3. Similarity Engine
- [x] Реализовать scale-independent признаки формы свечей (тело, тени, относительная волатильность, импульс и гэп).
- [x] Искать top-N по общей базе OTC-примеров, но строго в том же таймфрейме; исходная пара сохраняется в каждом совпадении.
- [x] Настраиваемые topK, порог сходства, минимум примеров, число голосов направления и lookback; значения по умолчанию 10 / 80% / 3 / 6 / 30.
- [x] Исключать примеры, вход которых не предшествует времени анализируемого сигнала; использовать только закрытые свечи до входа.
- [x] Возвращать список совпадений, исходную пару, направление, сходство, экспирацию и результат; отдельно показывать среднее сходство и историческую win rate.
- [x] Подключить ручной запуск анализа из окна разметки через IPC с проверкой доверенного renderer.
- [x] Сохранять настройки Top-N, порога, минимальных примеров/голосов и lookback в локальном settings.json.
- [x] Добавить хронологический walk-forward evaluator: предыдущий пример допускается только после завершения его участка и экспирации.
- [x] Показать в окне разметки точность и покрытие walk-forward проверки отдельно; это не режим торговли и не обещание будущей доходности.
- [ ] Получить подтверждение качества similarity score на размеченной выборке; 80% — порог структурного сходства, не вероятность выигрыша.
- [ ] Провести хронологическую out-of-sample проверку и подобрать калибровку score на данных пользователя.
- [ ] Добавить версионирование формулы признаков и snapshot настроек в журнал решений.

## Этап 4. Решения и исполнение
- [x] Фоновый scanner ставит OTC-пары в очередь по факту получения тиков и проверяет выбранные таймфреймы.
- [x] Для каждой новой закрытой свечи выполняет анализ, учитывая изменения OHLC, настроек и revision набора примеров.
- [x] Фоновый анализ продолжает работу независимо от пользовательского режима окна разметки; настройки выбора одного или нескольких таймфреймов сохраняются.
- [x] Сохранять причины сигнала/отказа, snapshot настроек, входные свечи и версию алгоритма.
- [x] Реализовать лексикографический ranking helper: сходство → подтверждающие голоса → согласованность → историческая результативность.
- [x] Реализовать изолированный trade-intent planner с pause guard, лимитом 1–10, дедупликацией и выбором лучших сигналов.
- [ ] Подключить planner к scanner и обеспечить сбор сигналов в общий временной batch перед распределением слотов.
- [ ] Хранить pending/open signal keys и сверять реальное число открытых сделок с платформой.
- [ ] Реализовать и проверить исполнение по неактивному инструменту или безопасную схему нескольких окон.
- [ ] Подключить паузу к торговому исполнителю так, чтобы она блокировала только новые сделки, но не сбор данных/анализ.
- [ ] Проверка режима DEMO/REAL перед исполнением и подтверждение фактически открытой сделки.

Критерий выхода: подтверждено, что каждая сделка относится к ожидаемой паре/направлению/экспирации и её результат подтверждён.
