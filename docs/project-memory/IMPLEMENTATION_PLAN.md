## Этап 1. Исследование рыночного потока
- [ ] Проследить реальные WebSocket события, схему updateAssets и идентификаторы OTC.
- [ ] Проверить доступность свечей неактивных активов.
- [ ] Спроектировать Market Data adapter для Electron без Chrome APIs.
- [ ] Сделать тестовый поток свечей нескольких пар, измерить пропуски/задержки.

- [ ] Нормализация относительных свечных признаков.

## Этап 4. Решения и исполнение
- [ ] Decision Engine с причинами входа/отказа.
- [ ] Snapshot настроек и версии алгоритма.
- [ ] Прототип исполнения для неактивного инструмента или безопасная схема нескольких окон.
- [ ] Защита от дубликатов и контроль открытых сделок.
- [ ] Пауза блокирует новые сделки, но не анализ.
- [ ] Лимит открытых сделок 1–10.

Критерий выхода: подтверждено, что каждая сделка относится к ожидаемой паре/направлению/экспирации и её результат подтверждён.
