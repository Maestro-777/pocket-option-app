# Руководство пользователя — Pocket Option Background

**Версия документа:** 1.0  
**Версия приложения в исходниках:** 0.1.1  
**Платформа первой версии:** Windows 11  
**Статус:** документация описывает текущую реализацию исходного кода. Работа приложения на реальном компьютере и совместимость с текущей версией сайта Pocket Option ещё должны быть проверены.

## 1. Назначение программы

Pocket Option Background — отдельное настольное приложение на Electron для управления сессией Pocket Option, ручной разметки исторических OTC-ситуаций, непрерывного анализа похожих свечных паттернов и осторожного DEMO-only исполнения сделок.

Программа открывает собственную панель управления. Сайт Pocket Option запускается только после нажатия пользователем соответствующей кнопки.

### Что программа делает

- открывает Pocket Option в отдельном окне;
- использует постоянный профиль браузерной сессии, чтобы сохранять cookies и авторизацию;
- показывает состояние сайта, сети и свежесть данных баланса;
- отображает баланс только того режима счёта, который сайт подтвердил адаптером;
- позволяет запросить переход между DEMO и REAL;
- предоставляет отдельный мини-виджет;
- выполняет периодические проверки и ограниченные попытки восстановления;
- записывает события в журнал и позволяет экспортировать журналы;
- содержит механизм проверки и установки обновлений приложения через GitHub Releases;
- позволяет размечать исторические примеры в отдельном окне;
- анализирует новые закрытые свечи по выбранным OTC-парам и таймфреймам;
- ведёт подробный журнал сигналов и причин отказа;
- содержит DEMO-only торговый контур с явным включением и паузой;
- ведёт отдельный журнал сделок и статистику результата.

### Чего программа не делает

- не выполняет сделки на REAL-счёте;
- не включает автоторговлю автоматически при запуске;
- не считает UI-клик подтверждением открытия сделки брокером;
- не гарантирует непрерывную работу сайта или соединения;
- не обходит авторизацию Pocket Option и не просит пароль;
- не управляет настройками или обновлениями самого сайта Pocket Option.

## 2. Установка и первый запуск

На текущем этапе в репозитории находится исходный код, а не готовый проверенный установщик. После подготовки установщика инструкция установки будет дополнена.

Для запуска из исходников потребуется Windows 11 и установленный Node.js LTS.

1. Получите папку `Pocket-Option-Background` из репозитория.
2. Откройте PowerShell в этой папке.
3. Выполните:
   ```powershell
   npm install
   npm run check
   npm start
   ```
4. Дождитесь открытия панели управления.

Если проверка `npm run check` завершилась ошибкой, сохраните текст ошибки и передайте его разработчику. Команда проверяет синтаксис JavaScript, но не заменяет полноценное тестирование приложения.

## 3. Главное окно

В главном окне есть пять разделов:

- **Главная** — состояние приложения, сайта, активного счёта и мини-виджета;
- **Мониторинг** — результаты проверок устойчивости и состояния соединения;
- **Журналы** — список событий с фильтрацией и экспортом;
- **Настройки** — параметры виджета, мониторинга и восстановления;
- **Обновления** — проверка, загрузка и установка новой версии приложения.

В верхней части отображается краткий статус сети. Кнопка со стрелкой обновляет отображаемую информацию о состоянии.

## 4. Запуск и управление Pocket Option

1. Нажмите **«Запустить Pocket Option»**.
2. Откроется отдельное окно сайта.
3. Войдите в аккаунт вручную средствами сайта.
4. При последующих запусках приложения используется тот же постоянный профиль Electron, поэтому сайт может сохранить авторизацию.

Сайт не открывается автоматически при старте панели управления.

### Показать, скрыть и перезагрузить сайт

- **Открыть Pocket Option** показывает уже созданное окно или запускает сайт, если окно ещё не создано.
- **Скрыть** убирает окно с рабочего стола, но не завершает приложение и не удаляет профиль.
- **Перезагрузить** перезагружает страницу сайта. Это может потребовать повторного ожидания загрузки и обновления данных.

Закрытие окна сайта кнопкой окна Windows также скрывает его, а не завершает приложение.

## 5. Авторизация и сохранение сессии

Профиль сайта использует постоянную Electron-сессию с идентификатором `persist:pocket-option-background`. Cookies и другие данные сайта хранятся в пользовательских данных приложения.

- Вход выполняется пользователем вручную.
- Приложение не запрашивает и не сохраняет пароль в своих настройках.
- Очистка или удаление пользовательского профиля может привести к выходу из аккаунта.
- Сохранение авторизации зависит также от правил Pocket Option и состояния самой сессии.

Не удаляйте папку пользовательских данных приложения, если хотите сохранить текущую авторизацию и настройки.

## 6. DEMO и REAL

На главной странице отображается активный режим счёта и один соответствующий ему баланс.

### Переключение

- Нажмите **DEMO** или **REAL**.
- При выборе REAL появится дополнительное системное подтверждение.
- После подтверждения приложение перейдёт на соответствующий маршрут сайта.
- Режим считается переключённым только после того, как адаптер сайта обнаружит выбранный тип счёта и баланс.

Если сайт не подтвердил переход, приложение сообщит об ошибке и не должно считать выбранный режим подтверждённым.

**Важно:** REAL — реальный счёт. Автоматическое исполнение приложения разрешено только на подтверждённом DEMO-счёте; на REAL оно заблокировано. Перед переходом внимательно проверяйте режим.

### Почему баланс может быть пустым

Знак «—» или сообщение об отсутствии свежих данных означает, что приложение не получило подходящее подтверждение от адаптера сайта. Возможные причины:

- сайт ещё загружается;
- пользователь не вошёл в аккаунт;
- изменились элементы интерфейса Pocket Option;
- сайт временно не передаёт ожидаемые данные;
- соединение потеряно или страница зависла.

Приложение намеренно не подставляет предполагаемый баланс. Данные считаются устаревшими, если последнее подтверждение получено более 15 секунд назад.

## 7. Мини-виджет

Мини-виджет — небольшое отдельное окно с режимом счёта, балансом и кратким состоянием подключения.

- Его можно включить в настройках или через системный трей.
- Окно можно перемещать мышью.
- Виджет не закрепляется поверх всех окон.
- Кнопка **«Сайт»** показывает окно Pocket Option или запускает его.
- Кнопка с режимом счёта запрашивает переключение DEMO/REAL; при переходе на REAL действует подтверждение.
- Кнопка **×** скрывает виджет.

Виджет не является независимым источником данных: он отображает состояние, полученное главным процессом приложения и адаптером сайта.

## 8. Системный трей Windows

После запуска приложение создаёт значок в области уведомлений Windows рядом с часами. Если значок не виден, проверьте меню скрытых значков.

Контекстное меню трея предоставляет команды:

- открыть панель управления;
- показать или скрыть Pocket Option;
- показать или скрыть мини-виджет;
- посмотреть краткий статус;
- запустить проверку состояния;
- перезапустить приложение;
- полностью выйти из приложения.

Закрытие главного окна не завершает программу: панель скрывается в трей. Для полного завершения используйте пункт **«Выход»** в меню трея.

Автозапуск вместе с Windows в текущей версии не настраивается и не включён.

## 9. Мониторинг и восстановление соединения

Программа выполняет две группы проверок:

1. Проверка доступности Pocket Option в сети — примерно каждые 30 секунд.
2. Полная диагностика приложения — при запуске, вручную и по расписанию. Интервал полной диагностики настраивается от 5 до 30 минут; значение по умолчанию — 5 минут.

Если сайт запущен, но проверка сети или свежесть сигнала сайта указывают на проблему, приложение может выполнить ограниченную попытку восстановления: подождать заданное время и перезагрузить страницу.

Текущие значения по умолчанию:

- порог попыток до перезагрузки — 3;
- ожидание перед восстановлением — 30 секунд;
- максимум перезагрузок — 3 за 10 минут.

Ограничения нужны, чтобы приложение не перезагружало страницу бесконечно.

### Результаты полной проверки

Проверка может включать:

- доступность главного процесса Electron;
- наличие папки данных;
- наличие системного трея;
- доступность сайта по сети;
- отзывчивость окна сайта;
- свежесть данных баланса и режима;
- наличие адаптера Pocket Option;
- проверки подключённых модулей;
- состояние торгового ядра.

В этой сборке непрерывный анализ сигналов подключён. DEMO-исполнение доступно только после явного включения и подтверждения DEMO-режима. Диагностика не считает это подтверждением реального открытия ордера.

Проверка доступности сайта не доказывает, что сайт полностью функционирует или что аккаунт готов к торговле.

## 10. Настройки

В текущем интерфейсе доступны следующие параметры:

| Параметр | Допустимые значения | По умолчанию |
|---|---:|---:|
| Показывать мини-виджет | Вкл./выкл. | Выкл. |
| Интервал полной диагностики | 5–30 минут | 5 минут |
| Количество сбоев до перезагрузки | 1–10 | 3 |
| Задержка перед восстановлением | 5–300 секунд | 30 секунд |
| Максимум перезагрузок за 10 минут | 1–5 | 3 |
| Автоматически проверять обновления | Вкл./выкл. | Вкл. |

После изменения нажмите **«Сохранить настройки»**. Значения сохраняются локально.

Параметр автоматической проверки относится к самому приложению, а не к Pocket Option. По умолчанию программа проверяет обновления после запуска и затем каждые 6 часов. Найденная версия загружается автоматически. Установка начинается по кнопке «Установить и перезапустить» либо при следующем штатном выходе из программы.

## 11. Журналы и экспорт

Раздел **«Журналы»** показывает события приложения. Доступны фильтр по уровню и поиск по тексту события.

Основной файл журнала — `application.log` в формате JSON Lines: одна JSON-запись на строку. В запись могут входить время, уровень, сообщение и дополнительные данные.

Кнопка экспорта создаёт ZIP-архив, содержащий доступные на момент экспорта:

- `application.log`;
- `settings.json`.

Перед отправкой архива третьим лицам проверьте его содержимое: журналы и настройки могут раскрывать технические сведения о работе приложения.

## 12. Обновления

Раздел **«Обновления»** проверяет наличие новой версии приложения через GitHub Releases репозитория проекта.

Обычный порядок:

1. Программа автоматически проверяет GitHub Releases после запуска и затем каждые 6 часов. Проверку также можно запустить кнопкой **«Проверить»**.
2. Если новая версия найдена, загрузка начинается автоматически; процент отображается в разделе обновлений.
3. После завершения нажмите **«Установить и перезапустить»**. Если не устанавливать сразу, загруженное обновление будет установлено при следующем штатном выходе из программы.

Автообновление работает только для установленной Windows-сборки и после публикации GitHub Release с версией выше установленной. Workflow `.github/workflows/release.yml` собирает NSIS-установщик и публикует артефакты electron-builder, включая `latest.yml`, при отправке тега вида `vX.Y.Z`. Для тестирования нужен предыдущий установленный релиз и следующий релиз с большей версией.

Обновление приложения и обновление сайта Pocket Option — независимые процессы.

## 13. Где хранятся данные

Данные находятся в каталоге Electron `app.getPath('userData')` для текущего пользователя Windows.

В нём приложение использует:

- `settings.json` — локальные настройки;
- `logs/application.log` — журнал событий;
- данные постоянной сессии Electron — профиль сайта и cookies.

Точный физический путь зависит от установки и профиля Windows. Не удаляйте эти данные без понимания последствий: это может сбросить настройки и авторизацию.

## 14. Типовые проблемы

**Сайт не запускается.** Проверьте подключение к интернету, затем попробуйте запустить или перезагрузить сайт. Посмотрите журнал на наличие ошибки загрузки.

**Баланс отображается как «—».** Дождитесь полной загрузки и ручного входа в аккаунт. Если свежие данные не появились, экспортируйте журнал и обратитесь к разработчику: возможно, изменились селекторы сайта.

**Переключение DEMO/REAL не подтверждается.** Не считайте переключение успешным только по нажатию кнопки. Проверьте фактический режим на странице Pocket Option и передайте разработчику журнал.

**Приложение не восстановило соединение.** Автовосстановление ограничено и не может исправить сбой сервера, блокировку, проблемы DNS, системный сон или ограничения сети. Попробуйте показать окно сайта и перезагрузить страницу вручную.

**Не удаётся обновиться.** Проверьте, опубликован ли GitHub Release с файлами установщика и `latest.yml`, а также доступен ли GitHub.

## 15. Безопасность и ответственность

- Не передавайте пароль от Pocket Option разработчику или в журнал.
- Не устанавливайте модули из неизвестных источников.
- Перед переходом на REAL убедитесь, что выбран нужный счёт.
- Автоторговля доступна только в DEMO и выключена при запуске. Включайте её только после проверки суммы, экспирации и режима счёта.
- Наличие статуса «Подключено» не является гарантией доступности торговых операций или финансового результата.

## 16. Историческая разметка примеров

Откройте раздел **«Разметка примеров»** и нажмите **«Открыть отдельное окно разметки»**.

В окне можно выбирать OTC-пару и таймфрейм, загружать доступную историю, задавать границы исторического участка, отмечать точку входа и направление ВВЕРХ/ВНИЗ, указывать экспирацию и сохранять независимый пример. Примеры можно просматривать, редактировать и удалять.

Примеры сохраняются отдельно от торговых сделок. Для поиска совпадений используются только свечи до точки входа; последующее движение относится к оценке результата и не должно попадать во входные признаки.

## 17. Непрерывный анализ OTC

Панель **«Непрерывный анализ OTC-пар»** позволяет выбирать один или несколько таймфреймов из S5, S10, S15, S30, M1, M2, M3, M5, M10 и M15, настраивать окно истории, частоту сканирования и параметры поиска.

Начальные параметры matcher: 10 лучших сравнений, сходство от 80%, минимум 3 подходящих примера и минимум 6 голосов за одно направление. Эти значения настраиваются. Сходство 80% не является вероятностью выигрыша.

Список **«Решения по новым свечам»** показывает сигналы и отказы. Для каждого решения доступны направление, число голосов, процент сходства, исторические совпадения и их исходы. Полный snapshot параметров сохраняется в журнале.

Пауза торговли не выключает сбор котировок, построение свечей и анализ.

## 18. DEMO-автоторговля

Автоторговля выключена при запуске. Чтобы включить её:

1. Запусти Pocket Option и войди вручную.
2. Убедись, что сайт подтвердил DEMO-режим и показывает баланс DEMO.
3. В разделе разметки/анализа проверь сумму и экспирацию.
4. Нажми **«Включить DEMO автоторговлю»**.

Кнопка **«Пауза»** блокирует новые входы и отменяет команду, если торговая кнопка ещё не нажата. Рыночные данные и анализ продолжаются. При переходе на REAL автоторговля автоматически выключается; исполнитель также проверяет DEMO-режим перед каждой командой.

Перед нажатием кнопки сделки приложение пытается подтвердить активную пару в DOM, применённую сумму и экспирацию. Если проверить их не удаётся, вход отклоняется. После UI-клика сделка получает статус **SUBMITTED_UNCONFIRMED** до события закрытия; это не подтверждение открытия брокером.

Несколько одновременных сделок ограничены до подтверждения, что события закрытия однозначно содержат пару. Неоднозначный результат не приписывается сделке наугад. После перезапуска незавершённые записи требуют автоматической сверки по событию или ручного подтверждения в списке сделок.

## 19. Статистика сделок

Статистика строится по закрытым и однозначно сопоставленным DEMO-сделкам. Отображаются количество WIN/LOSS/DRAW, win rate (без DRAW), чистый результат, кривая накопленного результата и разбивки по валютным парам, таймфреймам, направлениям, экспирациям и уровням сходства.

Неразрешённые и unmatched-события не включаются в win rate и чистый результат, пока не будут сопоставлены. Поэтому статистика может быть неполной, если сайт изменил формат события закрытия.
